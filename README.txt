FORTNITE RANDOM CHEST BOT — RAILWAY VERSION

This version does NOT include token.txt. Set the secret token in Railway Variables:
BOT_TOKEN = your Telegram BotFather token

Deploy this repository on Railway. Railway will run the Procfile worker command.
Commands: /start /addnick /delnick /players /go /stop
The bot simulates random chest moments; it does not read live Fortnite chest spawns.
